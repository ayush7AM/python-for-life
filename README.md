# Python for Life 🐍

A beautifully designed, single-page **Python Programming MCQ Crash Module** — perfect for quick revision and exam prep.

## Features

- **100+ MCQs** covering core Python topics
- **6 Units**: Basics, Data Structures, Control Flow, Functions, OOP, File Handling & more
- **Color-coded difficulty** — Easy, Medium, Hard
- **Print-friendly** A4 layout with clean typography
- **Zero dependencies** — pure HTML/CSS, no frameworks needed
