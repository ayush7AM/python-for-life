🛠️ 1. Setting up your Programming Environment

What is Python?

  • A high-level, interpreted, general-purpose language created by Guido van Rossum (first released 1991).
  • Interpreted = code runs line by line through the interpreter; no separate compile step needed by you.
  • Case-sensitive: Print ≠ print, Age ≠ age.
  • Uses indentation (not braces {}) to mark blocks of code.
  • Python files use the extension .py.

Python on Windows

  • Download the installer from python.org.
  • Tick "Add Python to PATH" during installation, so python works from Command Prompt.

📦 2. Variables — Naming & Using

A variable is a name that refers to a value. It's created the moment you assign to it with =. There's no need to declare its type (Python is dynamically typed).

x = 10          # x refers to an int
x = "ten"       # now x refers to a str — allowed!
a = b = c = 0   # same value to many variables
p, q = 3, 4     # multiple assignment
p, q = q, p     # swap in one line → p=4, q=3

Naming rules (very commonly asked!)

✅ Allowed❌ Not allowed
Letters, digits, underscore _Starting with a digit: 2marks
Starting with a letter or _: _total, marks2Spaces or symbols: my name, total$, a-b, @x
Any lengthKeywords: if, class, for, True…
💡 TipGood style is snake_case with meaningful names: student_name rather than sn. Print = 5 is legal (it's not a keyword, just a bad idea).

Keywords

  • Reserved words with special meaning. You can't use them as variable names.
  • Python 3 has 35 keywords. List them with import keyword; print(keyword.kwlist).
  • Only three start with a capital letter: True, False, None.
  • Others include: and or not if elif else for while break continue pass def return import from as in is lambda class try except finally raise global nonlocal del with yield assert async await.

Avoiding NameError

A NameError happens when you use a name Python hasn't seen yet: it was never assigned, it's misspelled, or it has the wrong case.

print(score)     NameError: name 'score' is not defined
Total = 50
print(total)     NameError  (T ≠ t)
print(Hello)     NameError  (forgot the quotes, so Python sees a variable)
📌 RememberFix it by assigning before use, checking spelling and case, and putting strings in quotes.

The left side of = must be a variable name, not an expression: x + 1 = 5 is a SyntaxError.

🔀 4. Conditional Execution (if / elif / else)

marks = 72
if marks >= 90:
    print("A")
elif marks >= 60:
    print("B")        # only the FIRST true branch runs
else:
    print("C")
B
  • Colon : after if, elif, else is required. Missing it is a SyntaxError.
  • The block must be indented consistently (4 spaces is standard). Otherwise IndentationError.
  • elif and else are optional. You can have many elifs but only one else, and it goes last.
  • An empty block isn't allowed. Use pass as a placeholder.
  • One-line conditional expression: result = "Even" if n % 2 == 0 else "Odd"
⚠️ MCQ Trapif x = 5: is a SyntaxError (you need ==). Also: several separate ifs can all run, but in an if-elif chain only one branch runs.

Nested conditionals

x, y = 5, 10
if x > 0:
    if y > 0:
        print("Both positive")
    else:
        print("Only x positive")
Both positive
💡 TipNested ifs can often be simplified with and: if x > 0 and y > 0:. An else belongs to the if at the same indentation level.

🔁 5. The while Loop

Repeats as long as the condition is True. The condition is checked before each iteration.

n = 1
while n <= 3:
    print(n)
    n += 1          # without this: infinite loop!
print("Done, n =", n)
1
2
3
Done, n = 4
  • Three parts: initialise → condition → update.
  • If the condition is False at the start, the body runs 0 times.
  • while True: with a break inside is a common pattern.

🪆 7. Nested Loops (for & while)

for i in range(1, 4):
    for j in range(1, i + 1):
        print("*", end="")
    print()
*
**
***
  • The inner loop runs completely for every single iteration of the outer loop.
  • Total inner executions = outer count × inner count. E.g. range(3) inside range(4) → 12 times.
  • break in the inner loop exits only the inner loop.

🎯 8. Random Numbers in Loops

import random
secret = random.randint(1, 10)

Loops + random are used for guessing games, simulations (coin tosses, dice) and generating random test data. _ is a normal variable name, used when the loop variable isn't needed.

📦 9. Encapsulation & Generalization

Encapsulation
Wrapping a piece of code inside a function so it can be reused by name and its details are hidden.
Generalization
Replacing a fixed value with a parameter so the function works in more cases.
# Step 0: plain code
for i in range(1, 11): print(2 * i)

# Step 1: ENCAPSULATION – wrap in a function
def print_table_of_2():
    for i in range(1, 11): print(2 * i)

# Step 2: GENERALIZATION – 2 becomes parameter n
def print_table(n, upto=10):
    for i in range(1, upto + 1): print(n * i)

print_table(7)     # now works for ANY number
📌 RememberFunctions start with def. A function without return returns None. So print(print_table(2)) prints the table and then None.

🧵 1. Strings — A Compound Data Type

A string is compound: it's made of smaller pieces (characters) that you can access individually. Strings are ordered and immutable.

s = "PYTHON"
#  P  Y  T  H  O  N
#  0  1  2  3  4  5     ← positive index
# -6 -5 -4 -3 -2 -1     ← negative index
s[0]       'P'
s[-1]      'N'   ← last character
len(s)     6
s[len(s)-1]'N'
s[6]       IndexError: string index out of range
s[0] = "J" TypeError: 'str' object does not support item assignment
⚠️ MCQ TrapLast valid index = len(s) - 1. s[len(s)] is an IndexError. To "change" a string, make a new one: s = "J" + s[1:].

Traversal (visiting each character)

for ch in "cat":              # by value
    print(ch)

i = 0                         # by index with while
while i < len("cat"):
    print("cat"[i]); i += 1

Slices s[start : stop : step]

s = "PYTHON"
s[1:4]     'YTH'     ← stop excluded
s[:3]      'PYT'     ← from start
s[3:]      'HON'     ← till end
s[:]       'PYTHON'  ← full copy
s[::2]     'PTO'     ← every 2nd char
s[::-1]    'NOHTYP'  ← reverse!
s[-3:]     'HON'     ← last 3
s[2:100]   'THON'    ← out-of-range slice: NO error
s[4:1]     ''        ← empty, NO error
💡 TipLength of s[a:b] = b − a (when in range). Indexing out of range gives an error; slicing out of range never does.

String comparison

Strings are compared character by character using their Unicode (ASCII) values, like dictionary order.

"apple" < "banana"   True
"Zebra" < "apple"    True   ← uppercase (65–90) < lowercase (97–122)
"10" < "9"           True   ← compares '1' vs '9' as characters
"app" < "apple"      True   ← prefix is smaller
ord("A"), chr(97)    (65, 'a')
📌 RememberASCII order: space (32) < digits '0'–'9' (48–57) < 'A'–'Z' (65–90) < 'a'–'z' (97–122).

The find function

"banana".find("n")      2    ← first occurrence
"banana".find("na", 3)  4    ← start searching from index 3
"banana".find("z")      -1   ← not found (no error)
"banana".index("z")     ValueError  ← index() raises error instead

# writing find ourselves (classic textbook version)
def find(word, letter):
    i = 0
    while i < len(word):
        if word[i] == letter:
            return i
        i += 1
    return -1

🔒 3. Tuples

Like a list, but immutable: it can't be changed after creation. Written with parentheses (strictly, the comma is what makes a tuple).

t = (1, 2, 3)
t = 1, 2, 3          # also a tuple (parentheses optional)
type((5))            <class 'int'>    ← just 5 in brackets!
type((5,))           <class 'tuple'>  ← single-element tuple needs a comma
t[0]                 1   ← indexing & slicing work
t[0] = 9             TypeError: 'tuple' object does not support item assignment
t + (4,)             (1, 2, 3, 4)  ← creates a NEW tuple
  • Only two methods: count() and index(). No append, remove or sort.
  • A tuple containing a list: the list inside can still change. t = (1, [2]); t[1].append(3) → (1, [2, 3]) ✅
  • Tuples can be dictionary keys; lists can't.

Tuple assignment

a, b = 1, 2          # unpacking
a, b = b, a          # swap! a=2, b=1
x, y = (10, 20, 30)  ValueError: too many values to unpack
name, dom = "ram@abc.com".split("@")   # 'ram', 'abc.com'

Tuples as return values

def min_max(lst):
    return min(lst), max(lst)   # returns ONE tuple
lo, hi = min_max([4, 9, 1])
print(lo, hi)                   1 9
print(divmod(17, 5))            (3, 2)  ← built-in returning a tuple
📌 RememberA function can "return multiple values" only because Python packs them into one tuple.

📖 4. Dictionaries

A collection of key : value pairs in curly braces. Look up by key, not by position. Dictionaries are mutable and keep insertion order (Python 3.7+).

d = {"apple": 50, "mango": 80}
d["apple"]           50
d["kiwi"] = 30       # new key, so it's added
d["apple"] = 60      # existing key, so it's updated
d["grape"]           KeyError: 'grape'
d.get("grape")       None   ← no error
d.get("grape", 0)    0      ← default value
"apple" in d         True   ← 'in' checks KEYS only
60 in d              False  (60 is a value, not a key)
len(d)               3      ← number of pairs
{}                   # empty DICT (not an empty set)
⚠️ MCQ TrapKeys must be immutable (int, str, tuple…). {[1,2]: "x"} gives TypeError: unhashable type: 'list'. Keys are unique: {"a":1, "a":2} → {'a': 2} (last one wins). Values can be anything and can repeat.

🪞 5. Aliasing & Copying

Aliasing: two names refer to the same object. A change through one name is seen through the other. This only matters for mutable objects (lists, dicts).

a = [1, 2, 3]
b = a            # ALIAS: same list, two names
b.append(4)
print(a)         [1, 2, 3, 4]   ← a changed too!
a is b           True

c = a[:]         # COPY (clone). Also: a.copy() or list(a)
c.append(5)
print(a)         [1, 2, 3, 4]   ← a unaffected
a == c[:4]       True
a is c           False  ← different objects

d1 = {"x": 1}
d2 = d1          # alias
d3 = d1.copy()   # independent copy
d2["x"] = 99
print(d1, d3)    {'x': 99} {'x': 1}
📌 Remember== checks if values are equal. is checks if it's the same object in memory. b = a never copies; it only creates another name.
